# 验收

自动测试使用虚构资料、localhost API 和固定 OCR 图片，不产生真实 API 费用。

## 自动检查

- 核心测试：规范化、版本隔离、数据库重开、DOCX 表格与字符、资料边界、同题失败重试、软超时后返回、硬超时、并发竞速和过期结果。
- API 契约测试：实际 Rig HTTP 适配器发送四类请求，原生图片与 OpenAI PDF 输入、思考文本过滤、错误脱敏和截断输出拒绝。
- 界面测试：首次建档、编辑启用、模型分配、字幕与快捷键配置、选区透明与拖动、字幕更新与滚动复位。此项使用预览适配器，不代替桌面 IPC 或 Windows 集成验证。
- Windows CI：编译、clippy、真实 CPU OCR 图片识别、NSIS 构建、静默安装、从安装目录运行 OCR。

## Windows 桌面人工验收

以下项目必须在实际 Windows 桌面执行；CI 的构建成功不代表这些项目已经通过。

1. 安装 EXE，首次启动显示 OCR 就绪；关闭主窗口后可从托盘恢复。
2. 添加自己的 API Key，测试模型连接，再重启确认密钥仍可用且界面不显示明文。
3. 导入 TXT、DOCX、PDF/图片，检查整理预览；取消任务、重启后重新运行，确认已完成文件被复用。
4. 修改草稿时，现场仍使用旧 active；确认启用后仅命中新版本答案。
5. 框选测试图片 `tests/fixtures/question.png`；验证 100% / 150% 缩放、多显示器及负坐标显示器。重启后选区仍在。
6. 移动/拔插显示器后旧选区应提示重新框选，不能读取错误区域。
7. 按识别快捷键，白底黑字字幕出现。重复按键时复用进行中任务或缓存；隐藏期间任务继续，显示后内容保留。
8. 调整字幕位置/尺寸，保存后重启仍保持。OCR 区域不应包含字幕自身。
9. 测试 API 超时、错误 Key、全部模型失败、软超时后返回。失败同题应能重试；新题不能被旧题覆盖。
10. 导出档案，检查不含 Key/连接；重新导入核对源文件、整理结果和准备答案。

## 时延测量

用同一台机器、同一组问题和固定模型参数，分别记录：

- 按键至 OCR 完成；
- OCR 完成至完整回答；
- 按键至屏幕可读；
- 缓存命中与未命中分开；
- 首次冷启动、连续使用分别统计中位数、P95、错误率和超 5 秒比例。

真实模型性能及 Windows GUI 全链路需要用户设备与已配置接口，不能由本地假接口测试推断。首次发行不承诺固定时延 SLA。
